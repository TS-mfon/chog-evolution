# API contract

Deployed routes live under `/api`; standalone Fastify uses the paths below. Errors use `{error,message,requestId,retryable}` and return `X-Request-Id`. Success, ERC-721 metadata and binary responses retain their documented shapes. Mutating wallet requests require the HttpOnly `chog_session` cookie. JSON requests are limited to 64 KiB, including chunked requests; shared Mongo rate buckets return 429 with `Retry-After`.

| Method and path                                                                                      | Behavior                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /health`, `GET /ready`                                                                          | Process health; readiness requires Mongo and schema version 3.                                                                                                                    |
| `GET /v1/config`                                                                                     | Public chain, collection, explorer and source feature settings; private RPC credentials are excluded.                                                                             |
| `POST /v1/auth/nonce`                                                                                | `{address,chainId}` creates an expiring single-use signed challenge.                                                                                                              |
| `POST /v1/auth/verify`                                                                               | `{message,signature}` consumes a valid nonce and sets the session cookie.                                                                                                         |
| `GET /v1/auth/me`, `POST /v1/auth/logout`                                                            | Restore or revoke a session.                                                                                                                                                      |
| `POST /v1/mints/prepare`                                                                             | Check demo chain, collection and supply; return a zero-value mint transaction for wallet confirmation.                                                                            |
| `POST /v1/mints/confirm`                                                                             | `{transactionHash}` verifies receipt, mint event, collection, token and current owner; registers the profile and queues its once-only quest. Safe to retry without minting again. |
| `POST /v1/profiles/discover`                                                                         | `{mode?,cursor?}` discovers current NFTs; returns `{items,partial,nextCursor}`.                                                                                                   |
| `GET /v1/profiles`                                                                                   | Owned profiles, checked against the configured chain and current owner.                                                                                                           |
| `POST /v1/profiles/register`                                                                         | Compatibility registration by identity; validates the RPC chain and owner.                                                                                                        |
| `GET /v1/traits`                                                                                     | Versioned catalogue of fixed identity and optional accessory/aura traits.                                                                                                         |
| `PATCH /v1/profiles/:id/traits`                                                                      | `{equippedTraitIds,expectedVersion}` plus `Idempotency-Key`; owner-checked transactional equipment change. Stale versions return 409.                                             |
| `GET /v1/passports/:id`                                                                              | Public profile and finalized accepted history, immutable before/after snapshots and recorded artwork.                                                                             |
| `GET /v1/metadata/demo/:tokenId`                                                                     | Public ERC-721 metadata after minted-existence verification; canonical equipped traits and published artwork or deterministic fallback.                                           |
| `GET /v1/artifacts/:id`                                                                              | Stream a published image or metadata file from GridFS.                                                                                                                            |
| `GET /v1/quests`                                                                                     | Active usable policies and their reward/evidence requirements.                                                                                                                    |
| `POST /v1/evidence/previews`                                                                         | `{profileId,questId?,url,text?}` plus `Idempotency-Key`; persist a preview before source/image work.                                                                              |
| `GET /v1/evidence/previews/:id`                                                                      | Owner-only source, captured images, eligibility, expiry, status and any resulting claim ID.                                                                                       |
| `POST /v1/evidence/previews/:id/retry`                                                               | Resume saved partial capture, or create a fresh generation after expiry; accepts `Idempotency-Key`.                                                                               |
| `GET /v1/evidence/media/:id`                                                                         | Public captured source image, bound to the exact submitted post.                                                                                                                  |
| `POST /v1/claims`                                                                                    | `{profileId,questId,previewId?,url?,text?}` plus `Idempotency-Key`; persist the immutable first claim attempt.                                                                    |
| `POST /v1/upgrades/evidence`                                                                         | `{profileId,previewId?,url?,text?}` plus `Idempotency-Key`; submit the maintained contribution quest.                                                                             |
| `GET /v1/claims`                                                                                     | Wallet-scoped claim collection.                                                                                                                                                   |
| `GET /v1/claims/:id`                                                                                 | Public sanitized source, attempt references, timeline, explanation and finalized award.                                                                                           |
| `POST /v1/claims/:id/retry`                                                                          | Owner-only idempotent recapture of source-unavailable evidence under a new numbered attempt; unknown submissions request finalized-state reconciliation. Rejections are terminal. |
| `GET /v1/evidence/:id`                                                                               | Immutable attempt-1 evidence JSON.                                                                                                                                                |
| `GET /v1/evidence/:id/attempts/:attempt`                                                             | Immutable exact evidence for a numbered attempt.                                                                                                                                  |
| `POST /v1/scans`, `GET /v1/scans/:id`                                                                | Wallet-scoped recent Monad mainnet scans, bounded coverage, checkpoints and candidate claim references.                                                                           |
| `GET /v1/activity`                                                                                   | Wallet-specific mint, scan, claim, social and evolution events.                                                                                                                   |
| `GET /v1/social/x`, `POST /v1/social/x/challenge`, `POST /v1/social/x/verify`, `DELETE /v1/social/x` | One-time bio-code verification from anonymous public X pages; verify body `{username}`.                                                                                           |
| `POST /v1/admin/quests`                                                                              | Create a reviewed policy version with the server admin key; contribution reward 1–75 XP.                                                                                          |
| `GET /v1/admin/claims/review`, `POST /v1/admin/claims/:id/review`                                    | Audited operator rejection; manual review cannot award XP.                                                                                                                        |
| `GET /v1/admin/metrics`                                                                              | Admin-only bounded hourly request/provider/job aggregates and queue counts.                                                                                                       |

Collection responses for profiles, quests, claims, activity and manual review accept `limit` (1–100) and opaque `cursor`, and return `nextCursor`. Ordering includes an ID tie-breaker. Passport history uses profile-bound version cursors so the previous image can be recovered across page boundaries. Clients must pass the cursor unchanged.

Previews expire after ten minutes. Capture workers use a lease and at most three automatic attempts; manual retry is explicit. The exact source snapshot is persisted before images, so recovery cannot mix changed post text with saved bytes. Consuming a preview checks its generation, source hash and request identity transactionally. Direct submissions and numbered retries also freeze a durable source before media work.

X requires verified stable numeric account identity, not a matching username alone. Renaming preserves identity; unlinking does not let a second wallet reuse it. Public pages are the default, no OAuth/API key required. Only attached photos from the exact post are captured: at most four JPEG/PNG/WebP images, 10 MiB each, 20 MiB combined, 16 million pixels each; animation is rejected. No image-content inference occurs. GitHub evidence pins a public repository commit and README with wallet attribution. User context is untrusted evidence.

Claims require an active, recently checked quest policy, or a versioned app-maintained evergreen policy. Idempotency is wallet-scoped and bound to request intent. Global source uniqueness prevents another quest, profile or wallet claiming the same contribution. Accepted contributions can grant 75 XP once per wallet per UTC finalization day, with a one-hour rewarded-contribution cooldown across midnight. Further accepted contributions are recorded with zero XP and produce no reward history/artwork job. Demo mint and X-link remain once-only (50 XP each); maintained mainnet activity is 25 XP per UTC block date.

Finalized decisions must match the exact claim attempt, wallet, profile, quest, policy and evidence hash. Pending, unavailable, malformed and rejected decisions cannot add XP. A transaction commits positive XP, profile, earned-trait provenance, history and artwork job together. Newly earned optional traits do not automatically equip. Equipment changes create their own source event/history/artwork job without XP. Only the current profile version can publish current artwork; previous snapshots retain their images.

Original metadata is read-only and remains separate from companion art. Profile fields `originalMetadataStatus`, `originalMetadataErrorCode` and `originalMetadataAttemptedAt` expose a failed refresh while retaining the last valid source metadata. Public evidence excludes sign-in messages, signatures and session cookies. Configure a publicly reachable HTTPS evidence base for GenLayer.
